# BlendShape Side Splitter

既存のシェイプキーを、メッシュのローカルX/Y/Z軸と指定位置で2方向に分割するUnity Editorツールです。両目用のキーを片目ずつ動かすためのキーへ分ける用途などを想定しています。

元メッシュをコピーし、既存キーを保持したまま2つのキーを追加します。モデル・画像・音声は付属しません。Humanoid/Generic共通で、VRChat SDK・Modular Avatar・特定シェーダーへの依存はありません。

## 前提条件

- Unity 2022.3.22f1で検証。その他のバージョンは未検証です。
- BlendShapeを持つSkinnedMeshRendererと、Read/Write可能なメッシュ。
- 選択した分割面の両側に変形があること。

Read/Writeが無効な場合はモデルのImport Settingsで有効にしてください。ツールはインポート設定を自動変更しません。

## 導入と使い方

1. `BlendShapeSideSplitter_1.1.0.unitypackage`をUnityの **Assets → Import Package → Custom Package** から導入します。
2. **Tools → Hiharu → BlendShape Side Splitter** を開きます。
3. 対象のSkinnedMeshRendererを指定し、分割するキーを選びます。
4. 分割軸と位置を設定します。通常の左右分割はX、位置0から確認しますが、モデルの座標によって異なります。正負は画面の左右やアバターの左右と同義ではありません。
5. 追加する2つの名前を設定します。既存名との重複はできません。
6. **分割メッシュを保存…** を押し、Assets内へ保存します。同名ファイルがある場合は別名で保存し、上書きしません。
7. 「保存後に対象へ適用」がOFFなら、生成したMeshをRendererのMesh欄へ手動で設定します。ONならシーン内の対象へ適用します。適用はUndoで戻せますが、生成ファイルは残ります。
8. RendererのBlendShapesで追加キーを個別に動かし、左右と境界を確認します。

追加キーの初期値は0。既存キーの順序・フレーム・名前は維持します。境界面に正確に載る頂点の変形は半分ずつに分け、両キーを同じ値にすると元キーと同じ変形量になる構成です。頂点位置・法線・接線の差分を分割し、複数フレームも維持します。

## VRChatで使う場合

本ツールはメッシュ編集だけを行います。Expressions MenuやFXアニメーションは作りません。元キーが既存アニメーションやまばたきから動かされている場合、その設定は残ります。**元キーと追加キーを同時に動かすと変形が加算される**ため、用途に応じて制御を整理してください。

実際のモデルへの見た目、SDKビルド、VRChat実機での動作は別途確認してください。単純な座標分割なので、中央をまたぐ口・頬などで滑らかな左右表情になる保証はありません。フェザーやウェイト調整、骨の自動判定は初版に含みません。

## 更新・削除・戻し方

- 更新は同じフォルダへ新しいパッケージをインポートします。
- メッシュを戻すにはUndo、または元のMeshをRendererへ再指定します。
- ツール削除は`Assets/BlendShapeSideSplitter`を削除します。生成メッシュは別ファイルのため残ります。
- 生成メッシュを削除する前に、それを参照するRendererを元に戻してください。
- 生成メッシュには元モデルの形状が含まれます。ツールのMITライセンスは元モデルや生成メッシュの再配布許可を与えるものではありません。

## 不具合時の確認

| 状況 | 確認点 |
| --- | --- |
| Toolsに表示されない | インポート完了とConsoleのコンパイルエラーを確認 |
| キーが選べない | MeshとBlendShapeを持つSkinnedMeshRendererを指定 |
| 片側にしか変形がないと表示される | 分割軸・位置・元キーを確認 |
| 左右が逆 | メッシュのローカル座標を確認。名前を正負に合わせて設定 |
| 変形が強すぎる | 元キーや別アニメーションとの重複を確認 |

## 環境チェックと診断結果コピー

**Tools → Hiharu → BlendShape Side Splitter**を開き、入力欄の下にある診断ボタンを使います。

**環境チェック**で、その時点の設定と対処の案内を表示します。**診断結果をコピー**は再チェックした結果をクリップボードへコピーします。**導入ガイド**はこのREADMEをブラウザーで開きます。

Read/Write、選択キー、分割軸・位置、頂点分布、追加名の重複、直接適用する対象を確認します。頂点の位置分布とキーの変形量は別のため、両側の変形は保存時にも検査します。

診断は設定を変更せず、アバター名・素材名・個人のファイルパス・Blueprint ID・Consoleログ本文を含めません。自動送信もしません。不具合相談ではコピーした結果に「操作した段階・期待した動作・実際の動作」を追記してください。ログや画像を別途添付する場合は、公開してよい内容か確認してください。

Package Managerに登録されていないAssets形式の依存パッケージは、バージョンを判別できないことがあります。コンパイルエラーがあると診断画面自体も開けないため、その場合はConsoleと前提条件を確認してください。診断は実モデルの見た目・他ギミックとの競合・VRChat実機の動作を保証しません。
